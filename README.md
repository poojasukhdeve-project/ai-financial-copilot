# 🤖 AI Financial Analyst Copilot

A professional **ETF comparison and analytics dashboard** built with Python and Streamlit that combines  
**financial data analysis, NLP-based sentiment evaluation, and an LLM-ready explainability layer**.

This project enables investors and analysts to compare ETFs (e.g., IWP vs IWS) using price trends, risk-return metrics, and news sentiment — all presented in a modern, dashboard-style UI.

---

## 🚀 Features

### 📊 ETF Analytics
- Side-by-side ETF comparison (Price, Returns, Volatility)
- Interactive price charts using Plotly
- Risk vs Return scatter plot for risk-adjusted analysis

### 🧠 NLP-Based Sentiment Analysis
- Processes financial news headlines
- Computes sentiment scores using NLP techniques
- Classifies sentiment as **Bullish / Bearish / Neutral**

### 📌 KPI Snapshot Cards
- Latest Close Price
- 1-Month Return (%)
- Annualized Volatility (Risk)
- News Sentiment Label

### 🤖 LLM-Ready Explanation Layer
- Modular architecture designed for LLM integration
- Generates human-readable investment insights
- Can be extended to use OpenAI / other LLM APIs
- Currently implemented using rule-based explainability for reliability and cost control

### 🎨 Modern Dashboard UI
- Dark theme with custom CSS
- Card-based KPI layout
- Sidebar ETF controls
- Tab-based layout to avoid excessive scrolling
